What happens
  1. Click Connect & Install and pick your ESP32-C3's serial port.
  2. It flashes the firmware + a 266k-domain blocklist (~30s).
  3. After it reboots, it makes a WiFi network called C3-AdBlock-XXXX — join it from your phone, pick your WiFi, type the password.
  4. Set it as your router's secondary DNS (or per-device), and ads are blocked network-wide. Dashboard at c3adblock.local.
  5. The blocklist updates by itself every day through GitHub Actions — nothing to do.

No WiFi credentials are baked into this build — you set them on-device, privately. RU ad networks (Yandex.Direct, AdFox, VK Ads, MyTarget) are covered out of the box.

Что произойдёт
  1. Нажмите Connect & Install и выберите COM-порт вашего ESP32-C3.
  2. Прошьётся прошивка + блок-лист на 266k доменов (~30 секунд).
  3. После перезагрузки появится сеть Wi-Fi C3-AdBlock-XXXX — подключитесь с телефона, выберите свою сеть, введите пароль.
  4. Укажите плату вторичным DNS на роутере (или на отдельных устройствах) — и реклама блокируется по всей сети. Дашборд: c3adblock.local.
  5. Список обновляется сам каждый день через GitHub Actions — ничего делать не нужно.

Пароли Wi-Fi в прошивку не зашиты — задаются на устройстве, приватно. Российские рекламные сети (Яндекс.Директ, AdFox, VK Ads, MyTarget) покрыты из коробки.
